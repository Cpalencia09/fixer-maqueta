# Fixer

- **App** (maqueta funcional con Firebase): raíz del repositorio (`index.html`).
- **Sitio web** de presentación: carpeta `sitio/` (inicio, cómo funciona, técnicos, descargar, contacto y legal).
  Las páginas se generan con `node sitio/_fuente/build.mjs` desde la raíz; los estilos y scripts están en `sitio/assets/`.
- Reglas de seguridad de Firestore: `firestore.rules` (se publican a mano en la consola de Firebase).
